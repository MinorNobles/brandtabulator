# Brandtabulator (working title)

Weekly rankings of brands, by category, by how actively their public record on Wikipedia and Wikidata is maintained. Published for people and for AI agents. Part of the Brand AI Report. Author: Michael Quinn.

- Site: served by GitHub Pages from this repository's root.
- `categories/`, `brands/`, `issues/`: generated pages (HTML + Markdown).
- `data/`: weekly CSV/JSON and the SPARQL queries that produced each brand list.
- `methods/`: metric definitions, verification process, corrections policy.
- `scripts/`: the pipeline that generates everything above.

Status: skeleton. No issues published yet.
